**Vice Rush** — a GTA 6 fan game. You are a wheelman in neon Vice City: pick up the package, thread the traffic, outrun the cops, and drop it off before the clock runs out. Six deliveries and the city is yours.

A complete top-down open-world driving game that runs offline in a desktop browser from static files: a 9×9-block city with traffic, a wanted system with police chases, missions with pay and clean bonuses, near-miss bonuses, repair pickups, a minimap, synthesized WebAudio engine/siren/music, particles, skid marks, screen shake, and a best haul kept in localStorage. No library, no build step, no network request.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Drive with WASD or the arrow keys, Space for the handbrake. P pauses, M mutes, R restarts, Enter starts. `?shot=start|play|chase|end&seed=N` stages a scene for a screenshot.
